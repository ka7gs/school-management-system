# نظام الإدارة المدرسية الموحد | Iraq School Management System

منظومة إلكترونية متكاملة لإدارة المدارس والكوادر التعليمية والطلبة وفق ضوابط وزارة التربية والتعليم العراقية، تدعم إدارة النتائج الامتحانية (نصف السنة والنهائية)، جدول الحصص الأسبوعي، سجلات الموظفين والمعلمين، وإعدادات المدرسة الرسمية.

---

## 🌟 أبرز المميزات (Features)

- **لوحة تحكم إدارية مركزية (Dashboard):**
  - إحصائيات سريعة عن أعداد الطلبة والمعلمين والشعب ونسب النجاح والحضور.
  - إمكانية تعديل بيانات المدرسة الرسمية (اسم المدرسة، المديرية العامة للتربية، الشعار، وختم الإدارة).

- **سجل الطلبة والشؤون المدرسية (Students Registry):**
  - إضافة وتعديل وحذف بيانات الطلاب.
  - فرز وبحث متقدم حسب الصف والشعبة ورقم القيد.
  - تصدير واستيراد البيانات.

- **سجل الدرجات والامتحانات (Grades & Examinations):**
  - رصد درجات الفصل الأول، امتحانات نصف السنة، الفصل الثاني، والامتحانات النهائية.
  - حساب المجموع والمعدل والنتيجة (ناجح / مكمل / راسب) تلقائياً طبقاً للوائح الوزارية.
  - **طباعة فردية مخصصة للنتائج:**
    - خيار طباعة نتيجة **نصف السنة فقط** أو **النتيجة النهائية فقط**.
    - ميزة الانتقال والرجوع التلقائي لطباعة الطالب التالي بسلاسة.

- **سجل الكادر التدريسي والوظائف (Staff & Teachers Registry):**
  - إدارة المدرسين والمعلمين والإداريين.
  - تحديد المواد الدراسية، النصاب الأسبوعي، والمؤهلات.

- **الجدول الأسبوعي التفاعلي (Weekly Schedule):**
  - جدول حصص أسبوعي قابل للتعديل والتخصيص لجميع الصفوف والشعب.

- **تقارير وإحصائيات تفصيلية (Comprehensive Reports):**
  - تقارير تحليلية لمستوى التحصيل الأكاديمي، الأوائل، ونسب الرسوب والنجاح لكل مادة وصف.

- **إدارة الحسابات والصلاحيات (User Accounts & Roles):**
  - إنشاء وتخصيص حسابات المستخدمين (مدير، معاون، مدرس، مشرف).
  - تحديد الاسم الرباعي، اسم المستخدم، كلمة المرور، ونوع الصلاحية والتخصص التدريسي.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Lucide Icons
- **Animation:** Motion
- **Exporting:** SheetJS (xlsx) للتقارير وملفات الجداول

## 🚀 التشغيل المحلي (Getting Started)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- npm أو bun أو pnpm

### خطوات التثبيت والتشغيل:

```bash
# 1. استنساخ المستودع (Clone the repo)
git clone https://github.com/ka7gs/school-management-system.git
cd school-management-system

# 2. تثبيت الحزم (Install dependencies)
npm install

# 3. تشغيل خادم التطوير (Start development server)
npm run dev
```

التطبيق سيعمل محلياً على: `http://localhost:3000`

## 📦 رفع المشروع إلى GitHub (Pushing to GitHub)

إذا أردت ربط هذا المشروع بمستودع جديد على حسابك في GitHub:

```bash
# 1. إنشاء مستودع جديد على GitHub (New Repository)
# 2. ربط المستودع البعيد:
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY_NAME>.git

# 3. التأكد من الفرع الرئيسي:
git branch -M main

# 4. رفع الملفات:
git push -u origin main
```
*(عند طلب اسم المستخدم وكلمة المرور، استخدم اسم مستخدم GitHub مع **Personal Access Token (PAT)** بدلاً من كلمة المرور).*

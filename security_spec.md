# Security Specification & Test Matrix

## 1. Data Invariants
- School documents (`/schools/{schoolId}`) must contain valid administrative metadata (`schoolName`, `directorate`, `academicYear`).
- Student records (`/schools/{schoolId}/students/{studentId}`) must have a valid `ministryId`, `adminId`, `fullName`, and matching path ID.
- Grade records (`/schools/{schoolId}/grades/{gradeId}`) must belong to valid students and valid Iraqi curricula subjects with numerical scores bounded between 0 and 100.
- Staff members (`/schools/{schoolId}/staff/{staffId}`) must have a unique `employeeCode` and valid job categories.
- User accounts (`/schools/{schoolId}/userAccounts/{userId}`) can only be modified by authorized administrators (Principal / Registrar), preventing self-escalation of roles.
- System notifications (`/schools/{schoolId}/notifications/{notificationId}`) can only be marked as read or generated by system administrators.
- Catch-all default deny protects all unknown collections and root access.

## 2. The "Dirty Dozen" Threat Payloads
1. **Unauthenticated Write**: Anonymous or unauthenticated attacker attempts to write to `/schools/default/students/st-fake`.
2. **Ghost Field Injection (Shadow Update)**: User adds an unauthorized `isSuperAdmin: true` field into a Student document.
3. **Extreme Payload String Flooding**: Submitting a 50KB name string to breach database volumetric limits.
4. **Negative or Overflow Grade**: Submitting a grade score of `-25` or `999` to corrupt average calculations.
5. **Unauthorized Role Escalation**: A teacher account updating their own `role` from `"teacher"` to `"principal"`.
6. **Path ID Poisoning**: Using non-alphanumeric/path traversal characters (`../../admin`) as `studentId`.
7. **Orphaned Sub-collection Write**: Creating a grade entry under a non-existent school ID without proper authorization.
8. **Malicious Notification Spam**: An unauthenticated user writing spam announcements into notifications.
9. **Staff Member Impersonation**: Modifying someone else's employee record without administrator authorization.
10. **School Identity Tampering**: Modifying ministry verification stamps or directorate credentials by unauthorized staff.
11. **Negative Service Years**: Setting staff `yearsOfService` to negative values.
12. **Blanket Query Scraping**: Attempting an unrestricted collection query without school membership.
